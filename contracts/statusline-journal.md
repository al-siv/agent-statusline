### EP-3 (status: implemented) — маркер левой границы: шеврон `❯` вместо бара с разделителем
touched: Specification («Сборка строки», «Цвета», «Защитная механика и байт-точность»), GATE-1

Проблема: текущий рендер маркера `▏` + серого разделителя даёт визуальный артефакт «двойной палки» (`▏ | M 400k …`) и расходится с примером в README (там маркер без разделителя). Решение пользователя (2026-08-17): маркер — шеврон `❯`, за ним обычный пробел перед первым непустым сегментом; разделитель ` | ` — только между сегментами. При пустом составе сегментов маркер выводится один, без хвостового пробела.

Дельта:

- Specification «Сборка строки»: маркер `▏` → `❯`, правило клея (пробел после маркера, ` | ` между сегментами).
- Specification «Цвета»: глиф маркера явно `❯` (gray, 90 — без изменений).
- Specification «Защитная механика и байт-точность»: упоминание глифа `▏` → `❯`.
- GATE-1: критерий без привязки к глифу («порядок сегментов и маркер левой границы»).
- `statusline-command.sh`: рендер маркера и клей первого сегмента.
- README: пример строки и строка таблицы сегментов тем же коммитом (видимое поведение меняется).

### EP-4 (status: implemented) — маркер левой границы: светлый серый шеврон
touched: Specification («Цвета», «Сборка строки», «Защитная механика и байт-точность»)

Проблема: шеврон `❯` в стандартном сером (ANSI 90, bright black) визуально тусклый. Решение пользователя (2026-08-17): более яркий оттенок серого — 256-цветная палитра, код `38;5;250` (светлый серый, ~#bcbcbc). Разделитель ` | ` остаётся gray (90).

Дельта:

- Specification «Цвета»: маркер `❯` — светлый серый `38;5;250`; разделитель — gray (90); деградация на терминалах без 256-цветной палитры (код игнорируется, цвет по умолчанию, строка не ломается — INV-4).
- Specification «Сборка строки»: «серый маркер» → «светло-серый маркер».
- Specification «Защитная механика и байт-точность»: то же уточнение.
- `statusline-command.sh`: отдельная переменная цвета маркера `C_MARKER` (`38;5;250`), разделитель на `C_SEP` (90).
- README: строка таблицы сегментов («Light-gray left-edge marker») тем же коммитом.
